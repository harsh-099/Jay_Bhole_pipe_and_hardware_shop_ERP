# 🏪 Jay Bhole Pipe & Hardware Shop ERP

A modern web-based **Enterprise Resource Planning (ERP) system** developed for managing the day-to-day operations of a Pipe & Hardware Shop.

The system provides a centralized platform to manage products, customers, suppliers, billing, purchases, inventory, credit (Udhari), expenses, reports, and other shop management activities.

## 🌐 Live Demo

🔗 **Live Application:**  
https://jaybholeshop-five.vercel.app/

---

## 📌 Project Overview

**Jay Bhole Pipe & Hardware Shop ERP** is a Django-based shop management system designed to digitize and simplify traditional hardware shop operations.

The application helps shop owners manage business activities from a centralized dashboard, reducing manual record keeping and making daily shop operations more organized and efficient.

## ▶️ How to Run

1. **Clone the repo**:
```bash
git clone https: https://github.com/harsh-099/Jay_Bhole_pipe_and_hardware_shop_ERP.git
cd Jay_Bhole_pipe_and_hardware_shop_ERP
```

2. **Install dependencies**:
```bash
pip install -r requirements.txt
```
3. **Apply database migrations**:
```bash
python manage.py migrate
```

4. **Create a superuser**:
```bash
python manage.py createsuperuser
```

5.**Run the development server**:
```bash
python manage.py runserver
```

6.**Open the application**:
```bash
http://127.0.0.1:8000/
```

7.**Django Admin Panel**:
```bash
http://127.0.0.1:8000/admin/
```
